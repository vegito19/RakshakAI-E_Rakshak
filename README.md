# 🛡️ Rakshak AI

**Rakshak AI** is an AI-powered multilingual Open Source Intelligence (OSINT) platform designed to assist law enforcement agencies in proactively identifying and monitoring potential public safety threats from publicly available social media sources.

The platform continuously collects data from supported public platforms, processes content in **English, Hindi, Gujarati, Hinglish, and Gujlish**, performs sentiment and threat analysis using modern NLP models, and presents actionable insights through a secure investigative dashboard.

Built with scalability, modularity, and security in mind, Rakshak AI leverages asynchronous data pipelines, intelligent threat scoring, multilingual translation, and geospatial visualization to help authorities rapidly detect emerging incidents, prioritize investigations, and maintain evidentiary records.

### Key Features

* 🌐 Public social media monitoring (OSINT)
* 🤖 AI-powered multilingual sentiment & threat analysis
* 🚨 Real-time threat scoring and alert generation
* 🗺️ Geospatial visualization of incidents across Surat
* 🔐 Secure role-based access control (RBAC) for law enforcement
* 📄 Chain-of-custody evidence report generation
* ⚡ Asynchronous processing using Redis queues
* 📊 Interactive analytics dashboard with live insights

Rakshak AI aims to transform publicly available online information into actionable intelligence, enabling faster response times and better situational awareness for law enforcement while respecting legal and ethical considerations around public data collection.
